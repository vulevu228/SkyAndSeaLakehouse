How the data gets here

1 Land. A Raspberry Pi collects OpenSky and AIS 24/7; daily .csv.gz files go to a Unity Catalog volume.
2 Bronze. Auto Loader streams only new files; every value is kept as text.
3 Silver. Typed columns. Drop rules: bad ICAO/MMSI, no position, out of range, 0/0. Warn rules keep the row and flag it: stale fixes, impossible speeds.
4 Gold. Star schema plus port calls (gaps-and-islands), enriched with the OpenSky registry, ICAO Doc 8643 and FAA sizes.
5 Serve. A file-arrival Job reruns the pipeline; Power BI imports gold through the SQL Warehouse, and this page is a snapshot export of that model.
Volunteer receivers, not official counts. Port calls match a local Polars build within 0.1 %.
Data: OpenSky Network state vectors and aircraft database · AIS positions · FAA Aircraft Characteristics Database · ICAO Doc 8643 · UN/LOCODE · land outlines Natural Earth (world-atlas) · aircraft photos from Wikimedia Commons (author and licence under each photo). 3D models are generic shapes scaled to each type's FAA span, length and tail height, not exact replicas. Pipeline: Databricks Lakeflow (bronze → silver → gold) · snapshot .
